# MoonProj 0.1.0 preview 1

This is the first LEPUSA-packaged macOS preview of the MoonProj Basic OPC.

## Included

- Rabbita desktop UI for the company, execution, delivery, assurance, and
  governance circuits.
- One release-quality dashboard where nine Gates and the three evidence
  dimensions read the same commit-level PostgreSQL ledger.
- Independent MoonClaw producer/reviewer workflow for bounded release evidence.
- A new in-app Guide and repository UI guide.
- LEPUSA supervision for the compiled MoonBit company service and UI gateway.
- Runtime-generated local session secrets and a loopback-only desktop session.
- Canonical MoonProj web logo and padded macOS application icon.

## Verification

- 11 Rabbita OPC tests passed with warnings denied.

## Requirements and limitations

- Architecture: Apple silicon (`arm64`). Minimum macOS: 11.0.
- Signing is ad hoc. This preview is not notarized because no Developer ID
  Application identity is installed. Control-click **MoonProj.app** and choose
  **Open** if Gatekeeper blocks first launch.
- PostgreSQL 18 and `psql` are external prerequisites. The release contains no
  database password. Configure standard PostgreSQL environment variables or a
  mode-`0600` `pgpass` file in the MoonProj LEPUSA app-data directory.
- Live engineering audits require a separately running MoonClaw daemon and
  local Moon Suite repositories. Missing dependencies remain unknown and keep
  release authorization locked.
- The real-estate ERP remains an extension pack; complete source-data and
  business-acceptance parity is not claimed by this preview.

## Security and data placement

Both HTTP services bind only to loopback. Runtime service/session secrets are
generated for each launch and are not stored in the app bundle. User data and
PostgreSQL credentials must remain outside `MoonProj.app` under the LEPUSA
application-data directory.
