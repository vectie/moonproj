# 负责人计划简报

在 Projects 现有计划编辑器中，选择“负责人计划简报”下的一位负责人。
页面立即显示其任务、原文计划成本、直接前置任务，以及跨负责人的输入与输出交接。
里程碑包含目标日期、完整验收条件和所需证据；风险包含原文程度、应对措施与任务引用。
“本人负责”与“任务上下文”分别标注直接分配和关联信息，不把相关条目重新分配给此人。

编辑计划后，简报使用最新草稿重新生成。选择“下载负责人简报 (.txt)”可保存
与页面相同的全文，供人工检查和分享。没有任务的负责人仍可查看自己负责的里程碑与风险。
未找到的任务或里程碑引用明确保留，供返回编辑器修正；此功能不要求草稿已经通过原生验证。

此视图不改动草稿、浏览器存储、保存版本或已准备结果，也不发起网络请求。
切换项目或账户会清除选择。负责人被移除后不能继续下载其旧简报。
日期与金额保持原文，没有计算工期、工作量、现金或完成情况。
仅包含当前负责人任务、其里程碑与风险、关联里程碑与风险和直接跨负责人依赖；
不是完整计划备份，也不是所有传递依赖的展开。完整依赖路径仍由现有依赖浏览器提供。

导出是计划草稿，不构成任务派发、外部发送、审批、合同、客户验收或付款。
自由文本、姓名和本地行引用会出现在文件中；人工分享前请检查内容。
保存、派发和业务授权仍使用各自现有流程。
